# CYBRLY

**I’m 14 and I built CYBRLY – a platform where I create custom projects for people.**  

CYBRLY is my first serious web project, built entirely from scratch to showcase my skills and manage future clients. While I’m just starting out and don’t have clients yet, this site demonstrates what I can build and serves as a foundation for my freelance work.  

---

## Features

- **Clean & Interactive UI** – Easy to navigate and visually appealing.  
- **Animated Elements** – Smooth transitions and interactive components for a fun user experience.  
- **Project-Ready Structure** – Organized for handling client projects in the future.  
- **Fully Built from Scratch** – Using HTML, CSS, and JavaScript.
